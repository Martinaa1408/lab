From aligned sequences to a tree

Paste aligned sequences in FASTA format. The tool counts differences between every pair, corrects them for multiple substitutions, and builds a tree with UPGMA or neighbour joining.

Tree

Distance matrix

The example uses six invented bacterial isolates. Jukes-Cantor: d = −¾ ln(1 − 4p/3). UPGMA assumes a constant rate of evolution and gives a rooted tree; neighbour joining does not, and its tree is unrooted (drawn here from the last join; small negative branch lengths, which neighbour joining can produce, are drawn as zero). Branch lengths match Biopython and SciPy.
